1. Mở thư mục AutoTV bằng Android Studio, chờ Gradle sync (Studio tự tạo gradle wrapper).
2. Build > Build APK(s). Cài APK lên điện thoại.
3. Mở app AutoTV trên điện thoại, nhập link M3U + trang web mặc định, bấm Lưu.
4. Android Auto: bật Developer settings (bấm 10 lần vào "Phiên bản"), bật "Unknown sources".
5. Kết nối xe, mở AutoTV từ launcher của Android Auto. Dùng nút Web / TV trên thanh hành động.
